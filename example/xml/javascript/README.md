# Generated JavaScript XML codec

The shared runner generates `schema.mjs` from
[model.serializer](../model.serializer), installs the locked MIT-licensed
[`@xmldom/xmldom` parser](https://github.com/xmldom/xmldom), and executes `main.mjs`.
The adapter and model mapping are generated by Serializer.

```text
order.xml
   |
decodeXml -> owning order
   |
encodeXml -> output.xml
```

`main.mjs INPUT OUTPUT` verifies namespace/attribute/child mapping, checked numbers,
ordered repeated tags, DTD refusal and resource limits. See the
[shared commands](../README.md). No browser globals or remote XML resolution are needed.
