# Independent malformed ZIP fixtures

These files are generated by [package_malformed_fixtures.py](../package_malformed_fixtures.py)
under its 0BSD license. Regenerate them with:

```text
python -B test/resources/package_malformed_fixtures.py
```

Python's standard-library `zipfile` produces and independently validates
`valid.zip`. It contains a DEFLATE model, a stored binary attachment and stored
OPC metadata. The script changes declared fields for the six `index` cases.
The four `integrity` cases retain coherent ZIP offsets/lengths and matching local
and central metadata while changing CRC, expanded size or exact DEFLATE framing.
Trailing/truncated compressed bytes repair all affected entry/directory offsets.

`cases.txt` names the same ten immutable inputs for C++ and actual generated
Python tests. Index cases must fail construction; integrity cases must pass ZIP
indexing and fail model-entry reading. Aggregate tests additionally check that
failure does not publish a candidate or alter the existing C++ destination.
