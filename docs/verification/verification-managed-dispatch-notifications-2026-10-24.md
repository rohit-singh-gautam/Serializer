# Managed dispatch and notifications verification, 2026-10-24

Windows x64 MSVC 19.51 C++23 Release, generated by compiler/runtime 2.34.0,
schema language 1.24.0. The first focused CTest run passed:

- 20 guarded edit-dispatch tests: five each under direct32, direct64,
  separate32 and separate64 profiles.
- 20 field/dependency-notification tests: five under each same profile.
- Eight Protobuf tests: binary/JSON/text and exact golden wrapper bytes under
  separate uint32/uint64 with fixed/compact native identities.

Build: `./make.ps1 configure -BuildDirectory out/build/ReleaseWindows`, then
single-worker CMake target builds. CTest also ran with one worker. Full log:
`out/build/managed-contracts-first-pass.log`.

The dispatch tests cover nearest/inherited overrides, exact-owner application
implementations, escaped/temporary implementation lifetime, rollback on caught
implementation exceptions, borrowed arguments and typed expected errors.
Notification tests cover stable base paths, ordinary child replacements, precise
changed entities, immutable before/after pins, lifecycle/membership dependencies,
namespace replacement and transactional output-budget failure.

This does not close MG09 portability or MG10 compact entity/history storage.
Whole-root decode/compare/validation/history costs remain. The passing Protobuf
wrapper matrix does not establish direct managed Protobuf storage, packed/view
managed records or recursive owning editors. The compiler rejection matrix,
full core suite, Linux, installed consumers and broader inheritance contracts
remain to be qualified against the final sources.

The same first run found allocator accounting, Windows pinned-file replacement
and temporary path-fixture failures in other target groups. Those failures remain
recorded in the complete log; this report does not claim the entire run passed.
