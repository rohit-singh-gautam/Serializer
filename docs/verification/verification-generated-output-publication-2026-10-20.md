# Generated-output publication qualification, 20 October 2026

[CMake integration](../guides/cmake_integration.md#preserve-unchanged-generated-files) ·
[Verification index](README.md)

Compiler/runtime **2.14.0** preserves the modification time of an existing
compiler artifact or depfile when its prepared bytes are identical. The private
compiler helper compares regular-file contents in bounded 64 KiB scratch space;
changed, missing, nonregular or unreadable paths fall through to the existing
writer. Public `stream.hpp` write behavior is unchanged.

## Preserved boundaries

All source/output ownership, canonical alias, hardlink and depfile checks run
before the equality shortcut. Backend preparation and formatting still complete
before publication. The XSD importer continues to protect an already reviewed
schema from a different import result. Neither skipped writes nor the helper
changes the CLI's generated filenames, successful diagnostics or depfile syntax.

This is a compiler-specific optimization. Changed files retain the previous
direct-write and partial-I/O behavior; the change does not add atomic batch
publication or crash-durability guarantees. Callers must still serialize changes
to the same paths.
